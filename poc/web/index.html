这份 PoC 保证了什么

      
    
        
  • 算法就是 src/ 里那一份：扫描、引用图、删除规则、压缩、10 项校验全部复用，没有重写。
    • 
        
  • 对拍证据：同一份示例站点（831,130 B），浏览器版与 CLI 版 gas 完全一致（208,275,550），
            16 个文本产物 sha256 逐字节相同。
    • 
        
  • 图片是唯一的差别：CLI 走 libimagequant 调色板量化（→ 398,127 B），
            浏览器走 oxipng 无损（→ 约 639 KB）。想更小就得把量化版 WASM 也搬进来。
    • 
        
  • 没有服务器、没有 API key、文件不出本机，断网也能跑。
