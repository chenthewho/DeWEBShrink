The gas modelTRK-02

The protocol does not compress for you. Every byte you upload is a byte you pay for forever.

TapeCode writes your site path-for-path into an on-chain contract. No gzip, brotli or WebP. The bill is fixed:

ConstantValueMeaning
CHUNK_BYTES24,000Chunks of 24,000 bytes — one chunk, one transaction
perChunk270,000 gasFixed cost per chunk (the tx, the directory slot, the event)
perByte235 gasEvery single byte, forever
地板价0.05 gwei (BSC)gasPrice = max(floor, min(live, 20 × floor))
Single-file limit8 MiBLarger files are skipped silently; the UI says nothing
The formula
gas ≈ chunks × 270,000 + bytes ×235
Reference price1 MB 纯数据 ≈ 0.0129 BNB ≈ $9.60BSC floor 0.05 gwei · BNB $747 · baseline 2026-10
Prices and congestion change the amount; this recalculates as you edit the assumptions.
Many small files cost more than one big file

Chunks round up per file. Ten 3 KB files = ten chunks = 2.7M gas of per-chunk overhead for 30 KB.

Change one file, pay for one file

Same path + sha256 is skipped. Changed files re-upload in full — 240 KB → 60 KB saves on every revision.

Don't publish junk

README.md, .map and design exports are billed by the byte. Hidden files (.shots/, .DS_Store) are skipped entirely.

How it worksTRK-04

Four steps, all local.

01
Scan

Read every path and price it: files, bytes, chunks, gas, money — and flag what the protocol skips.

02
Shrink

Minify text (never rename top-level globals); try image tiers to the PSNR threshold, keep the smallest.

03
Verify

Ten checks against the original: references, globals, Content-Type, image size, monotonic size.

04
Bill

Before/after, money saved, this revision's delta — zipped as .tape.zip.

Long-term costTRK-06

Iteration cost doesn't scale with site size — it scales with the files you touch.

Same path + same sha256 is skipped. Anything that changed is re-uploaded in full.
Implication: an 800 KB site changing only a 20 KB JS pays 20 KB per deploy. Big assets become free after one change — one-time cost; code is the recurring cost.

LimitsTRK-07

What we don't do is on this page, too.

SKIPPED
No font subsetting

Fonts are 176.5 KB — 44% of the shrunk total. Subsetting needs re-cut glyphs and a codepoint-coverage check, or text turns to tofu. The tool just reports: ~88 KB more.

SKIPPED
We never send a transaction

It only touches the file system — no transactions, no signing. Publishing still goes through TapeCode.

SKIPPED
.well-known/ can't be uploaded

A path segment starting with . counts as hidden and is skipped — no domain verification or ACME here.

SKIPPED
Files over 8 MiB fail silently

The protocol skips them silently. We flag them; the publishing page won't.

SKIPPED
Changing shrink settings re-uploads the whole site

Change a setting and nearly every file's bytes change — treated as brand-new content.

SKIPPED
Dead-file detection is conservative

It reads static references only; runtime names fall back to basename / dir-prefix matching — better to miss one than delete a live file.

SKIPPED
PSNR is not a model of the human eye

PSNR isn't a model of the eye; 42 dB is where these images looked identical. On another site, raise it and re-compare.

A shrink tool that hides its limits isn't one you should hand your site to.
